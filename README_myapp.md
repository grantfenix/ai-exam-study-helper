# 오늘 뭐 복습하지? — AI 시험 준비 도우미 (`myapp.py`)

> **경영과인공지능 시험 대비 맞춤형 Streamlit 복습 도우미**  
>  
> **이 프로젝트는 교수님이 제공한 예제 앱을 참고하여 사용자의 학습 방식에 맞게 기능을 추가하고 개선한 버전입니다.**  
>  
> **AI는 사용자가 입력한 자료만 사용하며, AI 결과는 사용자가 확인하고 선택한 뒤에만 저장됩니다.**  
>  
> **API 키는 저장소에 포함되지 않습니다.**

## 1. 프로젝트 개요 및 목적

### 💡 기획 배경
기존 범용 AI 도구는 외부 인터넷이나 검증되지 않은 문서를 무분별하게 참조하여 강의 범위와 동떨어진 환각(Hallucination) 개념을 생성하기 쉽고, 모든 화면 전환마다 불필요한 API를 호출해 토큰 낭비와 응답 지연을 유발했습니다.

### 🎯 프로젝트 목적
- **강의 범위 집중**: 학생이 직접 수업에서 정리한 핵심 본문만을 학습 컨텍스트로 제한하여 출제 범위 이탈을 원천 방지합니다.
- **학습 주도권 확보**: AI가 제안한 용어 카드나 문제는 즉시 저장되지 않으며, 학생이 내용을 직접 확인·수정·선택한 뒤에만 영구 저장합니다.
- **초고속·무비용 인터랙션**: 초고속 추론 엔진(Groq)을 기본 제공하며, 카드 넘기기·채점·오답 재풀이 등 모든 UI 조작은 로컬 메모리에서 API 호출 없이(0회) 즉각 동작합니다.
- **취약 개념 집중 관리**: 퀴즈 및 플래시카드에서 틀린 용어를 '약한 개념'으로 자동 누적 추적하여 완전 학습을 돕습니다.

## 2. 주요 기능

### 📊 1) 홈 대시보드
- **학습 요약 메트릭**: 등록 주제 수, 저장 용어 카드 수, 누적 퀴즈 횟수, 약한 개념 수를 실시간 집계.
- **🚨 집중 복습 약한 개념 Top 3**: 누적 오답 횟수가 많은 개념을 배지 형태로 시각화하여 우선 복습 유도.
- **💡 오늘의 추천 복습 주제**: 카드 등록 수가 적거나 복습 주기가 도래한 주제를 자동 추천.
- **최근 퀴즈 풀이 이력**: 최근 응시한 퀴즈의 일시, 정답률, 오답 용어 요약 제공.

### 📝 2) 자료 입력 & 관리
- **주제 등록/수정/삭제**: 주제명, 출처/주차(예: W01A), 학습 수준(시작 전/복습 중/완료), 학습 본문 관리.
- **용어 설명 및 Side-by-Side 비교**:
  - 본문에서 궁금한 용어를 입력하고 1클릭으로 개념 요약 생성.
  - 여러 AI 제공자(Groq, Gemini, OpenRouter 등)의 응답을 한 화면에서 나란히 비교할 수 있는 뷰어 제공.

### 🗂️ 3) 플래시카드 학습
- **AI 용어 카드 자동 제안**: 사용자가 저장한 자료만을 기반으로 핵심 용어 5~8개 생성 (용어, 뜻, 핵심 포인트, 예시, 신뢰도).
- **저신뢰도(`confidence: low`) 안전장치**: 신뢰도가 낮은 카드는 경고 배지와 함께 기본 체크 해제되어 사용자의 면밀한 검토 유도.
- **인라인 편집 및 중복 방지**: 카드의 뜻과 예시를 즉석에서 수정한 뒤 원하는 카드만 선별 저장 (기존 저장 카드와 자동 중복 배제).
- **인터랙티브 암기 모드 (API 0회)**:
  - 앞면(용어) 노출 → "뜻 보기" 버튼 클릭 시 뒷면(정답 및 핵심 포인트) 공개.
  - 🟢 **외웠어요**: 암기 완료 처리 및 학습 횟수 카운트.
  - 🔴 **다시 볼게요**: 취약 개념에 즉시 누적 기록.

### ⏱️ 4) 객관식 퀴즈 & 오답 재풀이
- **맞춤형 문제 출제**:
  - 문항 수(5문제 / 10문제), 난이도(쉬움 / 보통 / 어려움 / 섞어서), 제한 시간(없음 / 5분 / 10분), 출제 범위 선택.
  - 4지선다형 객관식 문제로 정답 위치(1~4번) 자동 무작위 분산 및 질문 유형("옳은 것은?", "가장 적절한 것은?" 등) 다양화.
- **실시간 1문항 풀이 인터페이스 (API 0회)**:
  - 상단 진행률 바 및 제한 시간 카운트다운 타이머.
  - 선택지 선택 후 "정답 확인" 클릭 시 즉시 O/X 채점, 상세 해설, 관련 핵심 개념 노출.
- **퀴즈 종료 및 결과 분석**:
  - 최종 정답률(%)과 함께 오답 용어는 약한 개념으로 자동 등록.
  - 🔄 **틀린 문제만 다시 풀기**: API 호출 0회로 이번 세션에서 틀린 문항만 즉시 재시험 응시 가능.

### 📥 5) 전체 데이터 & Markdown 내보내기
- **원클릭 Markdown 내보내기 (`복습_<주제명>.md`)**:
  - API 호출 0회로 로컬 데이터만 조합하여 완성형 마크다운 복습 노트 생성.
  - 포함 내용: 주제 기본 정보 및 출처, 저장된 본문 원문, 핵심 용어 카드 전체, 약한 개념 목록, 최근 퀴즈 결과 및 저장된 문제/정답/해설.
  - 브라우저 다운로드 버튼(`st.download_button`)을 통해 즉시 로컬 PC에 저장 가능.
- **저장소 백업 및 초기화**: 데이터 오염 방지를 위해 타임스탬프 백업 폴더를 자동 생성한 후 안전 초기화 지원.

## 3. AI 제공자 및 모델 선택 방법

사이드바에서 자유롭게 제공자를 변경할 수 있으며, API 키가 등록되지 않은 제공자는 친절한 사전 안내를 제공하여 앱이 절대 중단되지 않습니다.

| AI 제공자 | 지원 여부 | 기본 추천 모델 | 특징 및 권장 용도 |
| :--- | :---: | :--- | :--- |
| **Groq** *(기본값)* | `즉시 사용 가능` | `qwen/qwen3.8-27b` | **초고속 응답 (0.4초대)**, 용어 카드 생성 및 퀴즈 출제 최적화 |
| **Google Gemini** | `사용 가능` | `gemini-1.5-flash` | 방대한 문맥 이해 및 꼼꼼한 해설 |
| **OpenRouter** | `사용 가능` | `meta-llama/llama-3.3-70b-instruct` | 다양한 글로벌 오픈소스 거대 모델 활용 가능 |
| **한림 HAI** | `키 설정 필요` | `gpt-4o-mini` | 학교 포털 계정 키 설정 시 사용 가능 |
| **OpenAI GPT** | `키 설정 필요` | `gpt-4o-mini` | 고성능 표준 상용 모델 |

### 🛠️ 모델명 직접 입력 (Custom Model)
고정된 모델 목록 외에도 사용자가 직접 모델명을 텍스트 상자에 입력하여 자유롭게 테스트할 수 있으며, 잘못된 모델명을 입력하더라도 앱 오류 없이 친절한 가이드가 제공됩니다.

## 4. API 호출 규칙 (Zero-Call 원칙)

본 애플리케이션은 사용자 비용 절감과 초경량 쾌속 반응성을 보장하기 위해 엄격한 호출 격리 규칙을 준수합니다.

### 🟢 API 호출이 발생하는 시점 (오직 3가지 버튼 클릭 시 1회만 단독 호출)
1. **[1. 자료 입력 탭]** 용어 입력 후 **"설명"** 버튼 클릭
2. **[2. 플래시카드 탭]** **"AI로 카드 만들기"** 버튼 클릭
3. **[3. 객관식 퀴즈 탭]** **"AI로 문제 만들기"** 버튼 클릭

### 🔴 API 호출이 전혀 발생하지 않는 시점 (API 호출 0회)
- 탭 간 이동, 주제 선택, 본문 입력 및 저장/수정/삭제
- AI가 제안한 카드 검토, 체크박스 선택, 내용 수정, 영구 저장
- 플래시카드 앞/뒷면 뒤집기("뜻 보기"), 이전/다음 카드 넘기기
- 플래시카드 "외웠어요" / "다시 볼게요" 누적 기록
- 객관식 퀴즈 답안 선택, "정답 확인" 채점, 해설 열람, 다음 문제 넘어가기
- 퀴즈 타이머 카운트다운
- 🔄 **"틀린 문제만 다시 풀기"** (로컬 세션 문항 재활용)
- 📥 **"복습 Markdown 내보내기"** 파일 생성 및 다운로드
- 다크 모드 / 라이트 모드 테마 변경

## 5. 필요한 환경 설정 및 설치·실행 방법

### 시스템 요구사항
- Python 3.10 이상 권장 (3.12 테스트 완료)
- 의존성 라이브러리: `streamlit`, `openai`

### 1) 저장소 복제 및 가상환경 설정
```bash
# 저장소 복제
git clone <GitHub 저장소 URL>
cd <저장소 폴더>

# 가상환경 생성
python -m venv .venv

# 가상환경 활성화
# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# macOS / Linux:
source .venv/bin/activate

# 의존성 패키지 설치
pip install -r requirements_myapp.txt
```

### 2) 환경 변수 설정 (`.env`)
프로젝트 루트 디렉토리에 `.env` 파일을 생성하고 사용할 AI 제공자의 API 키를 입력합니다. (사용할 제공자의 키만 입력해도 동작합니다.)

```env
# Groq API 키 (권장 기본 제공자 - 빠른 응답)
GROQ_API_KEY=your_groq_api_key_here

# Google Gemini API 키
GEMINI_API_KEY=your_gemini_api_key_here

# OpenRouter API 키
OPENROUTER_API_KEY=your_openrouter_api_key_here

# OpenAI API 키 (선택)
OPENAI_API_KEY=your_openai_api_key_here

# 한림 HAI API 키 (선택)
HAI_API_KEY=your_hai_api_key_here
```

### 3) 앱 실행
```bash
streamlit run myapp.py
```
> 실행 후 브라우저가 열리지 않으면 터미널에 표시된 `http://localhost:8501` 주소로 접속합니다.

## 6. 데이터 저장 방식 및 구조

모든 데이터는 `data/` 디렉토리에 JSON 파일로 저장됩니다.  
Windows 환경의 파일 락(WinError 32)을 완벽히 방지하기 위해 **임시 파일 생성 후 원자적 교체(`os.replace`) 기법**을 적용하여 데이터 유실 위험이 없습니다.

```text
├── myapp.py                 # 메인 Streamlit 애플리케이션
├── storage.py               # 원자적 파일 I/O 및 데이터 영구 보관 엔진
├── ui_theme.py              # 다크/라이트 테마 및 CSS 스타일러
├── my_prompt.md             # AI 프롬프트 규격서
├── requirements_myapp.txt   # 실행 필수 패키지 목록
├── README_myapp.md          # 애플리케이션 가이드 및 기술 문서
├── .gitignore               # 민감 파일 및 데이터 제외 규칙
└── data/                    # 로컬 사용자 데이터 (저장소 업로드 제외)
    ├── topics.json          # 주제 목록, 출처, 학습 본문, 영구 저장된 용어 카드
    ├── weak_terms.json      # 오답 누적 약한 개념 데이터
    └── quiz_history.json    # 퀴즈 일시, 정답률, 오답 개념, 출제 문항 이력
```

## 7. 보안 및 개인정보 보호 안내

- **API 키 저장소 미포함**: `.env` 파일은 `.gitignore`에 등록되어 GitHub에 절대 커밋되거나 업로드되지 않습니다.
- **키 마스킹 보호**: 애플리케이션 내부 및 UI 화면 어디에도 API 키 값이 노출되지 않으며, 로그 출력 시 `[PROTECTED_KEY]`로 안전하게 마스킹 처리됩니다.
- **데이터 로컬 저장**: 사용자가 입력한 모든 강의 내용과 퀴즈 풀이 기록은 외부 클라우드가 아닌 사용자 로컬 PC(`data/`)에만 저장됩니다.
- **외부 데이터 무단 참조 배제**: 로컬 PC 내의 PDF 파일, 임의 폴더, 인터넷 검색 결과를 AI에게 임의로 전송하지 않습니다.

## 8. 알려진 제한 사항

1. **로컬 브라우저 세션**:
   - 퀴즈 진행 도중 브라우저를 새로고침(F5)하면 진행 중인 임시 퀴즈 세션이 초기화될 수 있습니다. (단, 이미 저장 완료된 주제와 용어 카드는 안전하게 유지됩니다.)
2. **대용량 PDF 자동 파싱 미지원**:
   - 본 앱은 시험 범위 요약본을 복사·붙여넣기하여 학습하도록 설계되었으며, 수백 페이지 분량의 원본 교재 통째 업로드는 지원하지 않습니다.
3. **오프라인 동작 제한**:
   - 용어 생성 및 퀴즈 출제 시에는 외부 AI API와 통신하므로 인터넷 연결이 필요합니다. (플래시카드 암기, 오답 재풀이, 내보내기 등은 인터넷 없이 동작 가능)

## 9. 향후 개선 아이디어
